# Security

For vulnerabilities, use GitHub's private vulnerability reporting on this
repository (Security → Report a vulnerability). Avoid public issues containing
private data or exploit details. If the reporting button is unavailable, contact
the maintainers through https://remotehumans.ai and request a private channel.

ScreenInc is an early preview. Use the latest release. Camera frames stay local.
The optional phone remote runs local HTTP with a random session pairing URL;
use trusted networks and stop the remote when finished. Do not share its URL.
